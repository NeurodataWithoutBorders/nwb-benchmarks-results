# NWB Benchmarks Results

Database for consolidating anonymous results from runs of the [NWB Benchmarks](https://nwb-benchmarks.readthedocs.io/en/latest/).

See [docs/threat-model.md](docs/threat-model.md) for the threat model (system map, STRIDE threat register, hardening plan, and diagrams) that this repository's security posture is measured against.
